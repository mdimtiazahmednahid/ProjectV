HOW TO RUN ON ANY WINDOWS PC:
--------------------------------------------------------------------------------
1. Extract this ZIP folder anywhere on your Windows PC (e.g., Desktop or Documents).
2. Double-click:
      Start_Facebook_Contest_Validator.cmd
3. On your very first launch:
   - It detects your Windows processor architecture (Intel/AMD x64, ARM64, or x86),
     sets up the native `.venv` runtime, generates `Facebook Contest Validator.exe`
     locally in this folder, and opens the application.
4. On every launch after that:
   - Double-click `Facebook Contest Validator.exe` (or `Start_Facebook_Contest_Validator.cmd`)
     to open the desktop GUI directly with zero console window!
